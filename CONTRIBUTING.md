# Contributing

This project aims to make the path from a coding-agent conversation to a
published small website clear and repeatable.

Open an issue for setup friction, broken instructions, accessibility problems,
or a site shape that the starter handles poorly. Include your operating system,
Node version, agent used, and the step that failed. Please remove customer
names, private briefs, contact details, account IDs, tokens, and domain DNS
records before posting logs or screenshots publicly.

For code changes, keep the starter fictional and broadly useful. Run
`npm run validate`, `npm test`, `npm run check`, and `npm run build` before a
pull request. `npm run audit` intentionally fails on this upstream starter;
it should pass only after a site owner personalises a copy.
